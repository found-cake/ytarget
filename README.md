# ytarget

Paper 26.3 CTF 문제 플러그인. 플레이어가 특정 좌표에 **연속 4틱 이상** 머무르면 문제를 푼 것으로 처리합니다.

## 빌드

```sh
./gradlew build   # -> build/libs/ytarget-<version>.jar
```

JDK 25가 필요합니다. 플러그인 jar에 Kotlin 런타임은 들어 있지 않고, 서버가 처음 로드할 때 `plugin.yml`의 `libraries`를 통해 Maven Central에서 `kotlin-stdlib`를 내려받습니다.

## 설치

1. jar를 `plugins/`에 넣습니다.
2. `plugins/ytarget/flag.txt`에 flag를 적습니다. 파일 끝의 개행만 제거하고 나머지는 그대로 사용합니다. 파일이 없으면 플러그인은 비활성화됩니다.
3. 서버를 시작합니다.

## 동작

- 매 틱마다 스펙테이터가 아닌 모든 플레이어의 Y좌표를 `String.format(Locale.ROOT, "%.5f", y)`로 문자열로 바꾼 뒤 MD5를 구해 `TARGET_MD5`와 비교합니다. 코드에는 해시만 있고 좌표 평문은 없습니다.
- 한 틱이라도 어긋나면 카운트가 초기화되므로 점프나 낙하로 잠깐 지나가는 것은 인정되지 않습니다.
- 솔브하면 다음 순서로 처리합니다.
  1. 인벤토리(커서 아이템 포함)를 비웁니다.
  2. 스펙테이터 모드로 바꿉니다.
  3. 플레이어가 밟고 있던 블록과 같은 층, 반경 8블록 안에서 충돌 박스 높이가 "솔브 시점 Y의 소수부"와 같은 블록을 모두 제거합니다. 블록 종류를 코드에 적지 않고 높이로 판별하므로 소스에서 힌트가 새지 않습니다.
  4. 채팅으로 flag를 보내고(클릭하면 복사됩니다), flag 이름이 붙은 부싯돌을 지급합니다.

값을 바꾸려면 `YTarget.kt`의 companion 상수(`TARGET_MD5`, `DECIMALS`, `REQUIRED_TICKS`, `CLEAR_RADIUS`)를 수정합니다.

<summary>출제자용 스포일러</summary>

- 목표 좌표: `Y = -62.43750` (MD5 `c7bd83421cc70961937a7cf680c53061`)
- `-63 + 9/16`이므로 **Y=-63에 놓인 석재절단기(높이 0.5625)** 위에 서 있으면 됩니다.
- Y=-63 층에 블록을 놓을 수 있어야 하므로 평지(superflat)나 직접 만든 아레나처럼 그 높이가 비어 있는 맵이 필요합니다. 일반 오버월드에서는 Y=-63이 기반암층입니다.
</details>
